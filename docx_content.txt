1.  The Challenge
You will build JobScout AI — an autonomous career agent that acts as a personal job-hunting assistant. The agent must independently analyze a candidate's CV, search for real-time job listings that match their profile, and justify every recommendation with clear reasoning.
This is not a simple search widget. It must operate as a true agentic system: it receives an input (a CV), breaks the task down on its own, queries external tools, evaluates results against the candidate profile, and presents ranked, reasoned job matches — all without manual step-by-step instructions from the user.

3.  Agentic Workflow (Expected Flow)
Your agent should follow this autonomous loop:
Ingest: Parse the uploaded CV and extract structured data (skills, role titles, years of experience, location preference).
Plan: The LLM generates a set of search queries optimized for the candidate's profile.
Search: The agent calls a real-time job search tool (Tavily, Serper, etc.) with each query.
Evaluate: Each job description is compared against the candidate profile using the LLM.
Rank & Explain: Jobs are scored and returned with a short reasoning paragraph per match.
Display: Results are presented in the dashboard with filters and sorting options.
